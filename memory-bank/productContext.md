# Product Context — TrailBrain

**Who it's for:** hikers, trekkers, and outdoor groups going to remote/hill-station
areas with little or no signal.

**Problem it solves:**
- No connectivity → no maps, no shared expense tracking, no way to coordinate a group.
- Typical trip apps need a server, so they die exactly where they're needed.

**The split-brain answer:**
- **Local brain** keeps the essentials working with zero signal (map, expenses,
  suggestions, photos, buddy last-known locations).
- **Online brain** plans the trip well when you have a connection, using an
  open-weight model + online resources (forecast, POIs, permits).

**Why open-source AI is the point:** the open model can run fully on-device, so
nothing (location, money, photos) leaves the phone in the backcountry. Data stays
off servers the user doesn't control; the model is inspectable and swap-able.

**User goals:** survive the trip offline, coordinate with friends, settle costs
fairly, and spend less time staring at a screen.
